# Design reference

`unm-archery-prototype/` is the designer's approved static prototype for the site redesign.
Start with [`unm-archery-prototype/HANDOFF.md`](unm-archery-prototype/HANDOFF.md): it is the spec, and the
prototype's code is the source of truth for every style and animation.

To view it, open `unm-archery-prototype/index.html`, `shop.html` or `book.html` in a browser.

Two folders from the designer's zip are not in the repo:
- `references/` (inspiration videos, screenshots and reference renders, some of them retail product shots that
  aren't ours to publish). It stays in the designer's handoff zip.
- `skills/`: those are installed in `.claude/skills/` instead.

The app's own copies of the assets it uses are in `public/` (`media/`, `arrows/`, `bows/`, `passes/`).
